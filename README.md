# 🎓 AI Study Pal

AI Study Pal is a Flask-based study assistant designed to help students practice multiple-choice questions and track their quiz performance.

## 🚀 Features

- 📝 Multiple-choice quiz generation
- ⚖️ Balanced questions across Easy, Medium, and Difficult levels
- ⏱️ Timed quiz experience
- 📊 Automatic score calculation
- 📈 Performance visualization using Matplotlib
- 💬 Personalized feedback based on quiz performance
- 🌐 Web-based interface built with Flask

## 🛠️ Technologies Used

- Python
- Flask
- Matplotlib
- HTML
- CSS
- SQLite
- Git & GitHub

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone git@github.com:Bojamma-06/AI-Study-Pal.git
cd AI-Study-Pal
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the application

```bash
python AI_app.py
```

Then open the local URL shown in the terminal.
